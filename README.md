# SnapNote - Quick Web Notes

Privacy Policy for the SnapNote - Quick Web Notes browser extension.

SnapNote is a privacy-first browser extension that helps users capture,
save, organize, and find useful information while browsing.

## What SnapNote Does

- Capture screenshots
- Capture custom areas
- Save selected text
- Save webpages and links
- Create quick notes
- Attach images, screenshots, links, and voice notes
- Search and organize saved content
- Export and import saved notes
- Backup and restore saved data

## Privacy

SnapNote follows a local-first approach.

Saved screenshots, notes, text, links, images, voice notes, and related
metadata are stored locally in the user's browser using IndexedDB.

SnapNote does not require an account and does not upload saved content
to a cloud service as part of its normal saving workflow.

SnapNote does not use third-party analytics or tracking to monitor
users' browsing activity.
